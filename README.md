# ley81-suite.com

Website for **Ley81·Suite**: a public marketing and product-information site, plus a gated admin area for license and patch distribution. Started 2026-10-04. Nothing is built yet; this folder is the starting kit (brand assets, product facts, reference docs, requirements) for the first build session.

## What's in here

| Path | What it is |
|---|---|
| `CLAUDE.md` | Context for any fresh coding session: what the site is, constraints, decisions already made, what is still open |
| `docs/PRODUCT_OVERVIEW.md` | What the product actually does today (written from the built app, not the original plan) with claims we can and can't make |
| `docs/WEBSITE_REQUIREMENTS.md` | Proposed site map, page-by-page content, the gated admin area, Cloudflare Access notes, open decisions |
| `docs/LICENSE_AND_PATCH_DISTRIBUTION.md` | What the desktop app expects from a license/update server, what already exists in the app, what doesn't |
| `docs/PRD_original.md` | The original PRD for the app. **Predates the build**: the real app differs (see the overview) |
| `docs/reference/` | Sibling-project and internal docs for background (license plan, update-channel plan, CIS status, threat model, implementation plan). Internal: do not publish |
| `brand/` | Logo (SVG + PNG), app icons, favicon set, web fonts, and `BRAND_GUIDE.md` |
| `assets/design-mockups/` | The original design handoff (Broadsheet design system, interactive mockup HTML, 11 screenshots). These are **mockups**, not screenshots of the shipped app |
| `assets/sample-reports/` | Real PDFs generated by the app (attestation, certificate, status report; EN/ES; with a sample consulting firm, plus one Company-install version) |
| `assets/report-title-page-design-samples/` | The three cover-page options and the chosen one (C) |
